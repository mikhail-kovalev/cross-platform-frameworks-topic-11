# Практические работы 2–9

Тема предметной области: **№28 — «Электронные устройства»**.

Проект последовательно развивается в практических работах 2–9. В практической
работе №2 создан статический экран на `StatelessWidget`: заголовок, описание
смартфона, локальное изображение, список характеристик и данные студента.

## Данные студента

Ковалев М.М., группа ИКБО-62-23.

## Запуск

```bash
flutter pub get
flutter run
```

## Проверка

```bash
flutter analyze
flutter test
```

В базовом экране используются `Scaffold`, `AppBar`, `Column`, `Row`, `Center`,
`Divider`, `Container`, `SizedBox`, `Padding`, `Text`, `Image`, `Icon`,
`Expanded` и `SingleChildScrollView`.
