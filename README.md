# Практические работы 2–9

Тема предметной области: **№28 — «Электронные устройства»**.

Проект развивается последовательно в практических работах 2–9. В практической
работе №2 был создан статический экран со смартфоном. В практической работе №3
добавлены пять локальных изображений, пользовательский шрифт и интерактивное
циклическое переключение устройств.

Устройство меняется двумя способами:

- нажатием кнопки «Следующее устройство»;
- нажатием на изображение устройства.

## Данные студента

Ковалев М.М., группа ИКБО-62-23.

## Запуск

```bash
flutter pub get
flutter run
```

## Проверка

```bash
flutter analyze
flutter test
```

Состояние текущего устройства хранится в `State`, а интерфейс обновляется через
`setState`. После пятого устройства список циклически возвращается к первому.
